# Online Retail Sales Database

## Overview

A MySQL-based database project designed to manage online retail sales, customers, products, orders, order items, and payments.

## Tools Used

- MySQL
- MySQL Workbench
- SQL

## Database Tables

- Customers
- Products
- Orders
- Order Items
- Payments

## Key Features

- Designed a relational database structure
- Implemented Primary Keys and Foreign Keys
- Added constraints for data integrity
- Stored customer and product information
- Managed orders and order items
- Recorded payment details
- Created sales reports using SQL JOIN queries
- Created a sales report view
- Generated an ER diagram

## SQL Concepts Used

- CREATE TABLE
- INSERT
- UPDATE
- SELECT
- JOIN
- GROUP BY
- Aggregate Functions
- VIEW
- Foreign Keys

## Reports

The project includes:

- Customer Order Report
- Detailed Sales Report
- Category-wise Sales Report
- Product Sales Report
- Payment and Order Report

## Conclusion

This project provided practical experience in MySQL database design, relational tables, SQL queries, joins, views, and sales reporting.
